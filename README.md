# ShinRyu · 牌河视觉档案

按照《mahjong_web_design_v4.pdf》实现的纯静态视觉档案。使用原生 HTML、CSS、JavaScript 和二维 Canvas，无需安装依赖、构建步骤或后端服务。

## GitHub Pages 部署

1. 打开仓库 **Settings → Pages**。
2. 在 **Build and deployment** 中选择 **Deploy from a branch**。
3. 选择 **main** 分支与 **/ (root)**，点击 **Save**。
4. 等待 GitHub Pages 的部署任务完成，访问 **https://5h1nryu.github.io/ShinRyu/**。

根目录的 `index.html` 是入口，所有资源均使用相对路径，支持 GitHub Pages 的 `/ShinRyu/` 项目子路径。`.nojekyll` 保证文件以静态资源发布。此仓库的检查工作流只验证代码，不会自动修改 Pages 设置。

## 本地预览与检查

```sh
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

不要直接通过 `file://` 打开：浏览器的 ES 模块安全规则需要 HTTP 服务。

可选检查，需要 Node.js 22 或更高版本，不需要 `npm install`：

```sh
npm run check
npm test
```

## 交互

- 初次打开：18 张蓝背牌进场；1100 ms 后可操作，不自动揭示。
- 点击任意牌：从该牌开始按距离产生一次性波纹揭示；单牌翻转 600 ms，全场最多 1200 ms。
- **作品**：盖牌时从第 2 行第 3 列揭示；正面时打开主图。
- **关于 / 联系**：盖牌时先揭示，完成后打开对应详情。揭示期间可记录一个待打开目标。
- 正面悬停：仅命中牌及其独立内容片段放大 4%；点击打开对应详情。
- 键盘：Tab 移动焦点，方向键在牌间移动，Enter / 空格激活；Esc 关闭详情。关闭后焦点回到原触发元素。
- 触屏：单击揭示或打开详情。
- 动画始终遵循默认设计：即使系统开启 **减少动态效果**，也从蓝背进场，保留悬停抬起、点击翻牌、运动模糊与详情动画。本次访问不自动揭示，刷新页面可重新验证。

## 设计实现

- 坐标统一为 1920 × 1080；全画布按 `min(视口宽/1920, 视口高/1080)` 等比居中。小屏也保持原构图，不重排，桌面不滚动。详情内容可独立滚动。
- 网格 6 × 3，牌面 164 × 224，间隙 4 px，翻转厚度 132。
- 主图以 500 × 452 的单元坐标切成六张 164 × 224 的独立纹理，裁切跳过真实 4 px 牌缝。其他单元也预先逐牌切分。没有覆盖整组牌的共享图片层。
- 翻身使用二维投影 `B = 164|cosθ| + 132sinθ`，只显示旧顶面、一个长侧面、新顶面。没有 CSS 3D、静置侧条或朝下隐藏面。
- 仅第 6 列三张牌有 `#05251B` 的硬边右影，静置宽 24 px，按当前轮廓与缩放同步绘制。其他牌没有独立投影。
- 牌体与独立片段使用 7 个时间样本的预乘 RGBA 合成；快门基准 8.333 ms，依速度缩短至翻身 12 px、进场/落定 2 px、悬停/按下 1 px 的拖影上限。硬影在当前时刻单独绘制，不进入模糊层。
- 详情有焦点约束、背景 `inert`、遮罩关闭、Esc 关闭及焦点恢复。Canvas 的语义由 18 个可访问的原生按钮提供。
- 中央盒与图像均为原创二维绘制；参考文档的外部照片未复制到网页。

## 更换内容

`assets/artwork.svg` 是主图源文件；`assets/study-circle.svg`、`assets/study-lines.svg` 是图集源文件。可以替换这些资源，然后在 `app.js` 中更新 `buildTextures()` 的牌面文字以及 `DETAILS` 的详情。

目前图像、项目介绍、文章、个人简介与联系说明均为明确标识的占位内容。联系入口指向真实的 GitHub 仓库，未虚构邮箱或个人经历。

文件说明：

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面与可访问的详情结构 |
| `styles.css` | 控制盒按钮、等比画布与详情样式 |
| `app.js` | 原创绘制、纹理切片、状态机、动画与交互 |
| `geometry.js` | 设计尺寸、投影、波纹与运动计算 |
| `assets/` | 本地原创 SVG 图像与站点图标 |
| `tests/geometry.test.js` | 布局、投影、阴影与关键帧验收 |
| `.github/workflows/check.yml` | main 分支与 PR 的自动检查 |
