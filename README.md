# ShinRyu · 牌河视觉档案

按照《mahjong_web_design_v4.pdf》及后续交互调整实现的纯静态视觉档案。使用原生 HTML、CSS、JavaScript 和二维 Canvas，无需安装依赖、构建步骤或后端服务。

## GitHub Pages 部署

1. 打开仓库 **Settings → Pages**。
2. 在 **Build and deployment** 中选择 **Deploy from a branch**。
3. 选择 **main** 分支与 **/ (root)**，点击 **Save**。
4. 等待部署完成，访问 **https://5h1nryu.github.io/ShinRyu/**。

根目录的 `index.html` 是入口，所有资源使用相对路径，支持 `/ShinRyu/` 项目子路径。`.nojekyll` 保证静态资源直接发布。检查工作流只验证代码，不修改 Pages 设置。

## 本地预览与检查

```sh
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

浏览器的 ES 模块需要 HTTP 服务，不要通过 `file://` 打开。

可选检查，需要 Node.js 22 或更高版本，无需 `npm install`：

```sh
npm run check
npm test
```

## 当前交互

- 初次打开：18 张蓝背牌进场；1100 ms 后可操作，不自动揭示。
- 点击任意蓝背牌：从该牌开始，按距离波纹翻到正面。单牌 600 ms，全场最多 1200 ms。
- **重置**：原“作品”按钮已改为重置。全部翻到正面后可点击，从左上角（第 1 行第 1 列）开始波纹翻回蓝背，随后可再次点击任意牌揭示。
- 蓝背、进场和翻转期间，重置按钮不可操作。揭示或重置期间重复点击忽略。
- 悬停：仅命中牌及其独立内容片段放大 4%；离开后恢复。正面点击只反馈按下效果，不打开窗口。
- 所有详情弹窗已移除。**关于 / 联系** 暂时保留控制盒上的外观，按钮未启用。
- 键盘：Tab 移动焦点，方向键在牌间移动，Enter / 空格激活。触屏单击揭示，点击重置翻回。
- 始终执行默认动画，即使系统开启 **减少动态效果**，也保留蓝背进场、悬停抬起、波纹翻牌和运动模糊。

## 设计实现

- 坐标统一为 1920 × 1080，按 `min(视口宽/1920, 视口高/1080)` 等比居中。小屏也保持原构图，不重排、不滚动。
- 网格 6 × 3，牌面 164 × 224，牌缝 4 px，翻转厚度 132。
- 主图以 500 × 452 的单元坐标切成六张独立纹理，裁切跳过真实牌缝；其余单元也在进场前逐牌切分。
- 翻身采用二维投影 `B = 164|cosθ| + 132sinθ`，只显示当前顶面和一个长侧面。揭示角度为 0°→180°，重置为 180°→0°，均保持中心固定与内容正向。
- 牌阵下方使用 `#05251B` 的连续遮光底层，填满所有横纵牌缝和圆角交汇处。第 6 列三张牌保留 24 px 的硬边右影，右影之间的行缝也用同色填满，衔接随当前轮廓变化。
- 牌体和逐牌内容以 7 个时间样本合成运动模糊；快门基准 8.333 ms，拖影上限为翻身 12 px、进场/落定 2 px、悬停/按下 1 px。阴影和牌缝底层不参与模糊采样。
- Canvas 的语义由 18 个可访问的原生按钮提供；重置按钮按当前状态启用。
- 中央控制盒与图像均为原创二维绘制，未复制参考照片。

## 更换内容

`assets/artwork.svg` 是主图源文件；在 `app.js` 的 `buildTextures()` 中更新牌面文字与源图即可。当前图像和文字为占位内容。

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面与可访问的控制按钮 |
| `styles.css` | 控制盒、按钮与等比画布样式 |
| `app.js` | 绘制、纹理切片、状态机与双向波纹交互 |
| `geometry.js` | 尺寸、双向投影、波纹与运动计算 |
| `assets/` | 本地原创 SVG 与站点图标 |
| `tests/geometry.test.js` | 布局、阴影、双向关键帧与波纹验收 |
| `.github/workflows/check.yml` | main 与 PR 的自动检查 |
