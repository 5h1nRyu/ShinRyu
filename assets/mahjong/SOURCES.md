# Riichi tile faces

Source: [FluffyStuff/riichi-mahjong-tiles](https://github.com/FluffyStuff/riichi-mahjong-tiles),
`Regular/`, commit `26e127ba2117f45cdce5ea0225748cc0cfad3169`.

The 37 SVGs are copied unchanged. They contain face artwork only, so the website's
existing ivory 3D tile provides the body. `Haku.svg` is intentionally blank.
See [LICENSE.md](LICENSE.md): all source artwork is dedicated to the public domain
under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

Notation: `0m`, `0p`, `0s` map to `Man5-Dora.svg`, `Pin5-Dora.svg`, `Sou5-Dora.svg`.
The other suit values 1–9 and the seven honors use the Regular set.

[M.LEAGUE official rules, Chapter 1, Article 2](https://m-league.jp/about/):
136 tiles, with one red five each of characters, circles and bamboo replacing one
regular five. The website samples from these copy counts, excluding the previous
face so that each completed reset changes the visible design.
